# InkWell — Responsive Blog Application

A beginner-friendly frontend project built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive homepage with blog cards
- Register and login demo flows
- Dashboard with story counts
- Create and publish blog posts
- Delete your own posts
- Browser `localStorage` persistence
- Mobile navigation menu

## Run the project
1. Extract the ZIP file.
2. Open the `blog_application` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Register an account, log in, and create a blog post.

## Files
- `index.html` — home page
- `login.html` — login form
- `register.html` — registration form
- `dashboard.html` — dashboard and post management
- `create-blog.html` — create/publish form
- `style.css` — responsive styling
- `app.js` — form logic and localStorage data handling

## Important limitations
This is a frontend learning/demo project. User accounts and posts are stored only in the current browser. Passwords are stored in plain text in localStorage, so **do not use a real password**. This is not secure authentication and is not suitable for production. A real application needs a backend, password hashing, server-side validation, and a database.
